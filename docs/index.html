怎麼算的，以及不能怎麼用

  1. 建案是推估的。成屋買賣檔沒有社區名稱欄位，只有門牌。這裡把「同一路段＋同一建築完工年月」的門牌歸為同一個建案，並顯示門牌範圍與棟數。預售屋檔才有登錄的真實建案名稱，另列一區。
  2. 屋齡以成交當下計算（成交年月 − 建築完成年月）。高鐵特區出現大量屋齡近 0 的整批登錄，是建商第一次移轉的新成屋；原始資料的負值已在此頁歸零顯示。
  3. 單價統計只採計住宅大樓與華廈，排除透天、店面、廠辦與純車位交易。極端低價多為親友間交易或含特殊約定，明細 CSV 的備註欄可逐筆查證。
  4. 區塊邊界是人為劃的。光埔與關埔在地理上重疊，這裡把慈雲路、埔頂各路歸光埔（好市多一帶），關新路、介壽路歸關埔；公道五慈雲路口的社區多半登錄為慈雲路門牌，因此計入光埔區。要調整改腳本裡的 REGIONS 即可。
  5. 最新一季尚未揭露完整。實價登錄申報後約 30 天才揭露，季檔會隨時間補齊，末季的筆數與中位數不宜單獨解讀為行情轉折。另有 140 筆因缺建築完成年月而排除。
